# Mum's Expenses — iPhone Personal Expense Tracker

## Deploying to GitHub Pages
1. Upload `index.html`, `manifest.json`, `sw.js`, and `icon-180.png` to the root of your GitHub repository.
2. Go to **Settings -> Pages** in your GitHub repository.
3. Under **Build and deployment -> Branch**, select `main` (and `/ (root)`), then click **Save**.
4. Open the published `https://<your-username>.github.io/<repo-name>/` URL in **Safari** on your mother's iPhone, tap **Share -> Add to Home Screen**, and tap **Add**.
